⚠️ Lokaler Webserver erforderlich

Flutter-Webanwendungen können aus Sicherheitsgründen aller modernen Browser (CORS / Same-Origin-Policy) nicht direkt über file:// (per Doppelklick auf die Datei) ausgeführt werden.

So startest du die Website:

# Im Projektordner:
cd build/web
python3 -m http.server 8080

Öffne anschließend in deinem bevorzugten Browser (z. B. Firefox):
http://localhost:8080
